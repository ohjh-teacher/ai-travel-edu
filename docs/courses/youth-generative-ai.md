## 작업 범위

사용자가 제공한 강의 계획서의 교육 목적, 7주 주제·주요 실습, 운영 방향을 과정 소개 화면에 반영했다. 초등 7주 과정의 강의 내용은 참조하거나 복사하지 않는다. 2~7주차 상세 강의안, 후기 문항과 QR은 별도 내용과 운영 조건을 확인한 뒤 작성한다.

## 1주차 구현

사용자가 제공한 1주차 통합 개발 지시서의 PART 1~7을 용산청소년센터 초등 과정과 같은 별도 1주차 화면, 16:9 화면 이동 방식으로 구성했다. 청년 과정 소개 화면에서는 1주차 링크만 열리고 2~7주차 카드는 그대로 둔다. ChatGPT 카드뉴스 도입, 메뉴 추천과 조건 비교, 생성형 AI 개념, 상황별 메시지, 답변 평가·수정, 프롬프트 통합과 새 채팅 검증, 정리 순서다. 프롬프트는 각 화면에서 원문 전체를 복사한다. 강사용 시간·운영 안내는 화면 밖의 별도 대화상자로 분리했다. 후기 기능은 아직 없다.

첨부 지시서는 일반 텍스트 원본이어서 `plain-text-v1` 방식으로 한 번만 접수했다. 원본 해시와 캐시 결과는 공용 작업 트리의 `tmp/material-intake-cache`에 기록했다.

처음 구현은 1주차를 과정 소개 페이지의 긴 본문에 한꺼번에 배치했다. 사용자 지적에 따라 이를 제거하고 초등 과정의 한 화면씩 넘기는 형식으로 수정했다. 카드뉴스 프롬프트의 원문 일치, 화면 순서·복사 대상, 빌드와 검증을 다시 확인한다. 로컬 파일 URL은 브라우저 보안 정책에 의해 열 수 없어 화면 시각 검수는 진행하지 못했다.

강의 계획서에는 회당 90분·총 10시간 30분이 적혀 있으나, 사용자가 2026-10-12에 매주 19:00~21:00(회당 120분)을 확정했다. 화면은 이 최신 답변에 맞춰 7회·총 14시간으로 표시한다. 음악·영상 생성 도구의 실제 이용 조건과 기관의 공식 강좌명은 게시 전 확인한다.

이 브랜치는 공통 안정화 변경과 다른 과정의 미커밋 변경보다 오래된 커밋에서 분기했다. 통합할 때 최신 카탈로그·매니페스트·포털 변경을 보존하고 이 과정의 등록 정보만 병합한다. 게시 전에는 기존 관리자 조회와 개인정보 권한, 학생 제출 흐름을 확인한다.
