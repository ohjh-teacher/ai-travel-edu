# 청년 7주 생성형 AI 정규과정 작업 기록

- 과정 ID: `youth-generative-ai`
- 제목: 생성형 AI, 일상에서 콘텐츠 제작까지
- 설명: 대화부터 조사·이미지·음악·영상 제작까지 직접 경험하는 7주 실습 과정
- 상태: `draft` (기관·운영 일정 미제공, 게시 요청 없음)
- 공개 경로 예정: `regular/youth-generative-ai/index.html`

## 구성

- 과정 소개와 7주 커리큘럼
- 공통 16:9 강의 화면에서 주차별 6개 슬라이드: 목표, 개념·안전, 입력 예시, 실습, 결과물, 후기 QR
- 1주차 주제 카드 → 2주차 사실 메모 → 3주차 글 → 4주차 이미지 → 5주차 음악 → 6주차 영상 → 7주차 점검·공유
- 후기 화면은 주차별 질문과 만족도를 기존 `week1Submissions` 컬렉션에 `courseId`, `questionVersion`, `questionAnswers`와 함께 저장

## 검증 및 게시 전 확인

- `node tools/project.mjs lock`, `build`, `validate` 통과. 자바스크립트 문법 검사 통과.
- 현재 작업 브랜치는 공통 보안 전환과 다른 과정의 미커밋 변경보다 오래된 커밋에서 분기했다. 합칠 때 최신 `content/catalog.json`, `config/project.manifest.json`, 포털 카드를 보존하며 새 과정 항목만 통합한다.
- 실제 운영의 관리자 조회·권한과 학생 제출은 게시 전에 계정이 준비된 환경에서 시험한다. 별도 관리자 화면이나 저장 규칙을 만들지 않는다.
- 후기 QR은 예정된 Hosting URL을 가리킨다. 해당 경로가 게시되기 전에는 학생에게 배포하지 않는다.
- 기관, 정확한 일정, 실제 사용할 생성 도구는 제공되지 않아 강의안에 임의로 명시하지 않았다.
