WEEK 01 · CHATGPT

같은 질문, 다른 결과!
AI에게 말하는 법

AI와 대화하면서 원하는 결과를 만들어 봅니다.

오늘의 학습 목표

  1. 생성형 AI와 프롬프트의 기본 개념을 이해합니다.
  2. 조건을 더해 결과를 바꾸고, 사실과 추측을 구분합니다.
  3. 결과를 평가·수정한 뒤 프롬프트 하나로 정리합니다.
  4. 새 채팅에서 완성한 프롬프트를 실행해 검증합니다.

도입 · 오늘 저녁 메뉴 카드뉴스

오늘 저녁, 어떤 요리가 먹고 싶으세요?

좋아하는 요리 하나를 선택하고 AI로 카드뉴스를 만들어 보세요.

카드뉴스 생성 프롬프트

요리명만 바꿔 ChatGPT에 붙여넣으세요.

아래 요리의 표지 카드뉴스 1장을 제작해 주세요.

요리명: [여기에 요리 이름 입력]

다음 조건을 반드시 지켜주세요.

- 대한민국에서 널리 알려진 대표 집밥 레시피를 기준으로 음식의 특징을 자연스럽게 반영합니다.
- 결과는 카드뉴스 1장만 제작합니다.
- 다른 페이지나 레시피 내용은 포함하지 않습니다.

디자인 구성
- 완성된 요리 사진을 화면의 약 70% 이상 크게 배치합니다.
- 요리명을 크고 선명하게 표시합니다.
- 음식의 매력을 표현하는 한 줄 소개를 넣습니다.
- 하단에는 감성적인 한 줄 문구를 넣습니다.

디자인 스타일
- 프리미엄 요리책 또는 푸드 매거진 표지 스타일
- 따뜻한 자연광과 실제 음식처럼 사실적인 사진
- 크림톤 배경과 브라운 계열 제목
- 여백이 많은 깔끔한 레이아웃
- 따뜻한 집밥 감성
- 읽기 쉬운 큰 글씨
- 고급스럽고 세련된 분위기

텍스트는 모두 자연스러운 한국어로 작성합니다.
  1. 원하는 요리 이름을 정합니다.
  2. 프롬프트의 요리명을 바꿉니다.
  3. ChatGPT에서 이미지를 생성합니다.
  4. 완성된 결과를 확인합니다.

함께 이야기해요

  • 어떤 요리를 선택하셨나요?
  • 마음에 드는 이미지가 나왔나요?
  • 생각했던 모습과 비슷한가요?

이런 프롬프트, 직접 만들어 보고 싶지 않으세요?

실습 ① · 같은 AI, 달라지는 조건

오늘 저녁 메뉴를 추천받아 봐요

같은 ChatGPT 대화에서 요청을 이어가며 결과가 어떻게 달라지는지 비교합니다.

1. 첫 번째 요청

오늘 저녁 메뉴 추천해줘.

2. 인원과 재료 추가

2명이 먹을 거야. 냉장고에는 돼지고기, 두부, 대파, 달걀이 있어.

3. 까다로운 조건 추가

그런데 10분 안에 완성해야 하고, 추가로 장을 볼 수 없어. 특별한 손님에게 대접할 음식이라 평범하지 않았으면 좋겠어. 이 조건을 모두 고려해서 다시 추천해줘.

4. AI에게 스스로 점검 요청

방금 추천한 메뉴들이 내가 말한 조건을 모두 충족하는지 하나씩 점검해줘. 특히 실제 조리시간, 사용할 수 있는 재료, 손님 대접에 적합한지를 검토해줘. 충족하지 못하거나 확실하지 않은 조건이 있다면 솔직하게 알려줘. 지금은 새로운 메뉴를 추천하지 마.

결과를 비교해요

  • AI가 처음 추천한 메뉴와 조건을 더한 뒤의 메뉴는 어떻게 달라졌나요?
  • 어떤 조건이 반영됐고, 다른 재료가 필요한가요?
  • 실제로 10분 안에 만들 수 있고, 추가 장보기 없이 손님에게 낼 수 있나요?

AI가 자신 있게 추천한 내용도 실제로 가능한지 확인해야 합니다.

기본 개념 · 방금 한 실습과 연결

생성형 AI와 프롬프트

생성형 AI는 사용자의 요청에 따라 글, 이미지, 음악 등 새로운 결과물을 만들어주는 인공지능입니다.

프롬프트는 AI에게 전달하는 질문이나 요청, 조건 등의 입력 내용입니다.

예: “오늘 저녁 메뉴 추천해줘.” → “2명이 먹을 거야.” → “10분 안에 완성해야 해.”

요청 → 결과 확인 → 조건 추가 → 다시 확인 → 수정

프롬프트는 처음부터 완벽하게 작성할 필요가 없습니다.

실습 ② · 상대방에 따라 달라지는 메시지

약속에 늦는다는 말을 어떻게 전할까요?

먼저 기본 메시지를 새 채팅에서 작성한 뒤, 상대방을 바꿔 결과를 비교합니다.

기본 요청

약속 장소에 20분 늦을 것 같아. 상대방에게 보낼 메시지를 작성해줘.

이 메시지는 누구에게 보내는 것처럼 느껴지시나요?

A. 20년 지기 친구

약속 장소에 20분 늦을 것 같아. 20년 지기 친구에게 보낼 메시지를 작성해줘.

B. 처음 만나는 거래처 담당자

약속 장소에 20분 늦을 것 같아. 처음 만나는 거래처 담당자에게 보낼 메시지를 작성해줘.

C. 강의를 기다리는 교육생

강의 시작 시간에 20분 늦을 것 같아. 강의를 기다리는 교육생들에게 보낼 메시지를 작성해줘.

결과를 비교해요

  • 말투와 내용은 어떻게 달라졌나요?
  • 상대방이 꼭 알아야 할 정보는 무엇인가요?
  • 우리가 알려주지 않은 사실이 메시지에 포함되어 있나요?

자연스럽고 그럴듯한 문장이라고 해서 모두 사실은 아닙니다.

실습 ③ · 답변 검토와 수정

AI의 답변을 다시 살펴봐요

앞서 만든 메시지 중 하나를 골라 같은 대화에서 검토를 요청합니다.

1. 받는 사람 입장에서 평가

방금 작성한 메시지를 받는 사람의 입장에서 평가해줘. 내가 실제로 알려준 사실과 네가 임의로 추가한 내용을 구분하고, 상대방이 불편하거나 부담스럽게 느낄 표현이 있는지도 검토해줘. 지금은 메시지를 수정하지 말고 문제점과 이유만 알려줘.

AI가 찾은 문제점은 타당한가요? 불필요한 지적은 없나요?

2. 필요한 내용만 남겨 다시 작성

내가 알려주지 않은 지각 사유나 강의 운영 계획을 임의로 만들어 넣지 마. 상대방에게 꼭 필요한 내용을 중심으로 자연스럽고 간결하게 다시 작성해줘. 메시지 작성에 반드시 필요한 정보가 부족하다면 먼저 질문해줘.

AI가 만든 답변도, AI가 스스로 내린 평가도 최종 판단은 사람이 합니다.

실습 ④ · 재사용 가능한 프롬프트

여러 번의 대화를 하나로 정리해요

대화 통합 요청

지금까지 우리가 대화하면서 정한 조건과 수정 사항을 하나로 모아줘.

다음에도 비슷한 상황에서 사용할 수 있도록 하나의 프롬프트로 만들어줘.

내가 실제로 제공한 정보와 AI가 추측한 내용을 구분하고, 필요한 정보는 직접 입력할 수 있도록 빈칸으로 남겨줘.

완성된 프롬프트 점검

  • 필요한 조건이 빠지지 않았나요?
  • AI가 추측한 사실이 포함되지 않았나요?
  • 서로 충돌하는 규칙은 없나요?
  • 다음에도 사용할 수 있나요?
  1. 완성된 프롬프트를 복사합니다.
  2. 새 채팅을 시작해 붙여넣습니다.
  3. 첫 번째 답변을 확인합니다.
  4. 의도대로 작동했는지 판단합니다.

프롬프트를 완성하는 것과 실제로 잘 작동하는 것은 별개입니다.

아래 시간은 90분 핵심 활동 기준입니다. 실제 수업 시간 19:00~21:00의 나머지 시간은 현장 실습 속도에 맞춰 조정합니다.

  1. 도입 · 약 10분 카드뉴스는 흥미를 여는 활동입니다. 완성도를 평가하거나 프롬프트 구성 요소를 분석하지 않습니다. 수강생에게 “방금 사용한 프롬프트를 직접 만들 수 있으신가요?”라고 묻고 본 수업으로 연결합니다. 이미지 생성이 제한되면 강사 시연으로 대체합니다.
  2. 메뉴 추천 · 약 15분 재료를 알려준 것과 그 재료만 사용하라고 제한한 것은 다릅니다. 다른 재료가 나왔다고 바로 오류라고 단정하지 않고 조건을 점검하게 합니다.
  3. 개념 · 약 10분 카드뉴스, 메뉴 추천, 조건 변경을 생성형 AI와 프롬프트의 예로 연결합니다. AI는 앞선 대화를 참고하지만 추측이 항상 맞지는 않음을 설명합니다.
  4. 상황별 메시지 · 약 20분 A·B·C를 가능하면 별도 새 채팅에서 실행합니다. 사전 Gemini 테스트에서는 말하지 않은 ‘교통체증’을 추가한 사례가 있었으나 ChatGPT에서 같은 결과를 보장하지 않습니다. 실제 결과에서 알려주지 않은 사실을 찾게 합니다.
  5. 검토·수정 · 약 15분 AI의 자기평가도 완전하지 않을 수 있습니다. 수강생이 문제점의 타당성을 판단하도록 돕습니다.
  6. 프롬프트 통합 · 약 15분 새 채팅에서 추가 질문이 먼저 나오더라도 곧바로 실패로 판단하지 않습니다. 프롬프트의 규칙과 빠진 정보에 비춰 적절성을 평가합니다.
  7. 정리 · 약 5분 요청부터 재사용까지 여섯 단계를 함께 복습하고 다음 주 인터뷰 방식으로 연결합니다.

빠르게 마친 수강생에게는 각 섹션의 결과 확인 질문을 더 살펴보게 합니다. 특정 AI 답변을 정답으로 고정하지 않습니다. 1주차는 ChatGPT만 사용하며 다른 AI와 비교하지 않습니다.
